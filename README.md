 project description
Tea Bubble Counter is a completely unnecessary computer-vision project that counts the
number of bubbles appearing on the surface of a cup of tea. Because apparently,
someone needed to know exactly how bubbly their tea is.
The problem (that doesn't exists)
Nobody knows exactly how many bubbles are floating on top of their tea.
This serious and completely imaginary problem has remained unsolved for generations.
The solution(that nobody asked for)
Our system uses Python and OpenCV to detect and count the bubbles on the surface of
a cup of tea using a camera.
Simply show the tea to the camera, and the system will analyze the image and display
the bubble count.
Because manually counting tea bubbles is apparently too much work.

Implementation 
For software
-The project uses Python and OpenCV to capture the tea surface through a camera.
The image is processed to identify bubbles based on their shape and appearance.
Detected bubbles are counted and the final number is displayed on the screen.
Basic Working
1. Start the Python program.
2. The camera captures the tea.
3. OpenCV processes the camera frame.
4. The tea surface is detected.
5. Bubbles are identified using image processing.
6. Each detected bubble is counted.
7. The total bubble count is displayed
